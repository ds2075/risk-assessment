# Оценка риска клиента (НС ПОД/ФТ)

Веб-сервис: загружаете Excel-таблицу клиентов → получаете ту же таблицу
с итоговым баллом, уровнем риска, обоснованием и листом «Подробный отчёт».

## Структура

| Файл | Что внутри |
|---|---|
| `app.py` | веб-сервер (Flask): загрузка, обработка, скачивание |
| `risk_scoring.py` | алгоритм проверки и подсчёта баллов |
| `risk_config.py` | методика: веса, пороги, отраслевые нормы, списки стран |
| `templates/` | страницы сайта |
| `static/template.xlsx` | пустой шаблон таблицы |
| `static/example.xlsx` | пример с тестовыми клиентами |
| `requirements.txt`, `render.yaml` | настройки для Render |

## Запуск на своём компьютере

```bash
pip install -r requirements.txt
python app.py
```
Открыть http://127.0.0.1:5000

Без сайта, только алгоритм:
```bash
python risk_scoring.py таблица.xlsx
```

## Публикация на Render

1. Создайте репозиторий на GitHub и загрузите в него **содержимое** этой папки
   (`app.py` должен лежать в корне репозитория).
2. Зайдите на https://render.com → **New → Blueprint** → выберите репозиторий.
   Render прочитает `render.yaml` и всё настроит сам. Нажмите **Apply**.
   *Или вручную:* **New → Web Service** → репозиторий →
   Build Command `pip install -r requirements.txt`,
   Start Command `gunicorn app:app`, тариф Free.
3. Через 2–3 минуты сайт будет доступен по адресу вида
   `https://risk-assessment-xxxx.onrender.com`.

**Важно про бесплатный тариф:** после 15 минут без запросов сервис «засыпает»,
первое открытие после этого занимает ~30–60 секунд. Перед защитой откройте сайт
заранее, чтобы он проснулся.

## Как изменить методику

Все баллы и пороги — в `risk_config.py` (словарь `W`, список `LEVELS`, `PROFILES`).
После изменения сделайте commit и push — Render пересоберёт сайт автоматически.
Списки FATF (`FATF_BLACK`, `FATF_GREY`) обновляйте после каждого пленума FATF
(февраль, июнь, октябрь).
